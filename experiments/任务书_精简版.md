# 任务书（精简版）：两处小改动，防住"被挑出一个致命质疑"

## 项目定位说明

本项目是**个人兴趣作品，用于 GitHub 展示**，不是投稿论文。因此本任务书**只做两件事**，其余统计严谨化改造（多组重连对照、手写 t 分布、50 分钟重训）**已明确放弃**，不做。

这两件事共同的目的只有一个：**避免被懂行的人一眼看出"数据口径有问题"**。

预计总工时：**约 25 分钟**，改动不到 20 行，**无需重新训练**。

# 改动 1（必须）：修正"拓扑优势"的措辞

## 为什么

当前 `checkpoint.json` 里写着：

```json
"topologyAdvantagePercent": 3.7075143688355925
```

配套的终端输出（`train.js` 第 270 行）写着：

```
🏆 生物拓扑归纳偏置优势 (Topology Gain): +3.7%
```

**问题**：这个 `+3.7%` 是**单次抽样**的结果。用不同的测试种子组复测，符号会翻转：

| 测试种子组 | 生物连接组 | 随机重连 | 差异 |
|---|---|---|---|
| 80001+ | 1461.5 帧 | 1409.3 帧 | **+3.71%** |
| 90001+ | 1518.0 帧 | 1575.1 帧 | **−3.62%** |
| 70001+ | 1480.9 帧 | 1482.8 帧 | **−0.13%** |

配对 t 检验：`t = −0.053, p ≈ 0.958` → **无统计显著差异**

**风险**：任何熟悉连接组研究的人（例如 flydino 的作者群体）看到「生物拓扑优势 +3.7%」都会追问统计检验。一旦发现符号翻转，"优势"这个说法就会变成把柄。

**而 flydino 作者自己的官方声明是**：

> 证明了学习控制和对电路活动的依赖，**而非生物拓扑的优越性**。

所以改成与之口吻一致的说法，从「吹了一个会被戳破的牛」变成「诚实报告的阴性结果」——后者在开源科研类项目里是**加分项**。

# 改动 2（建议）：固定随机基线的种子

## 为什么

`train.js` 第 254-256 行：

```js
  // 7. 随机未训练权重基线 (Random Weights)
  const randWeights = new Float64Array(PARAMETERS);
  for (let i = 0; i < PARAMETERS; i++) randWeights[i] = (Math.random() - 0.5) * 1.5;
```

**`Math.random()` 未固定种子**，导致：
- 任何人 clone 仓库重跑训练，`randomPolicy` 那一行数字都不同
- 实测自报 `322.5 帧`，独立复现得 `317.1 帧`
- README 里若写了"可复现"，这一行就是反例

**这是所有基线里唯一没有固定种子的**（其他基线如 idle / drift / silenced 都是确定性的）。

## 改哪里（共 1 处）

### 在 `train.js` 中新增确定性 PRNG

在文件顶部（`const graphData = ...` 之后、`evaluateCandidate` 之前）插入：

```js
/**
 * mulberry32 —— 确定性伪随机数生成器 (固定种子，保证全流程可复现)
 * 与 src/brain/connectome.js 中的实现保持一致。
 */
function mulberry32(a) {
  return function() {
    let t = a += 0x6D2B79F5;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

### 修改第 254-256 行

**现在：**

```js
  // 7. 随机未训练权重基线 (Random Weights)
  const randWeights = new Float64Array(PARAMETERS);
  for (let i = 0; i < PARAMETERS; i++) randWeights[i] = (Math.random() - 0.5) * 1.5;
  const randRes = evaluateOnTestSeeds(testSeeds, bioBrain, randWeights, 'normal');
```

**改成：**

```js
  // 7. 随机未训练权重基线 (Random Weights) — 固定种子，保证可复现
  const randRng = mulberry32(20260914);
  const randWeights = new Float64Array(PARAMETERS);
  for (let i = 0; i < PARAMETERS; i++) randWeights[i] = (randRng() - 0.5) * 1.5;
  const randRes = evaluateOnTestSeeds(testSeeds, bioBrain, randWeights, 'normal');
```

**注意**：`mulberry32` 返回 `[0, 1)`，所以 `(randRng() - 0.5) * 1.5` 的语义与原 `(Math.random() - 0.5) * 1.5` 完全一致，只是变得确定。
