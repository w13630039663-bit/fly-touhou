# P4-1「让 W 可塑（Hebbian）」实验报告

日期：2026-09-16
问题：给冻结的真连接组加一条 Hebbian 局部突触可塑性规则，会有什么改变？能不能让果蝇更强？
方法：先写探针标定（固定读出层），再把算子落进引擎、接进网页，最后做**协同训练 + 跨 CEM 种子复现 + 交叉环境检验**。

---

## 1. TL;DR

**P4-1 真的改变了系统，但没有可复现的能力提升。**

| 检验 | 结果 |
|---|---|
| W 会不会动 | 会。一局 1800 帧内线性漂移、不收敛 |
| 会不会变强 | **不能判定**。同一臂换一颗训练随机种子，与冻结臂的差值从 **+82 帧翻转为 −17 帧** |
| 训练噪声有多大 | **冻结臂自身跨 CEM 种子的极差就有 63.3 帧** —— 与「效应」同量级 |
| 读出策略本身更优吗 | 不更优。h5 权重放进冻结环境只有 1373.6（vs 冻结臂 1369.5，胜 6 / 负 7 / 平 7） |
| 最终裁决 | **效应量 ≤ 噪声 ⇒ 不能称为提升。** 与 P0 那次「+2.9% 假象」是同一类错误 |

**结论：P4-1 的价值是叙事与科普，不是能力。** 叙事上它把「冻结的真连接组」升级为「真连接组 + 生物可塑性」，溯源链不断；科普上它是一个现成的「大脑为什么需要稳态」演示。但作为变强的手段，它可以结掉了。

## 2. 代码改动（本次唯一动过的源码）

### 2.1 必修隐患：`eWeightBase` 是指针别名，不是副本

```js
// 改动前（src/brain/connectome.js:111）
this.eWeightBase = this.eWeight;          // ⚠️ 同一个数组对象
```

W 从冻结改为可塑之前，这行**无害** —— 因为没人写过 `eWeight[]`。但 Hebbian 是**就地**改写（`eWeight[e] += ...`），一旦开启：

- `eWeightBase` 会跟着一起变 → `applyDnGains()` 的「基准镜像」失效
- `restoreBioWeights()`（恢复生物权重）**永远无法还原** —— 果蝇的原始连接组在跑完第一局后就永久丢失

这是 P4-1 的**第一件必修**，与可塑性功能无关，属于「开功能前必须先拆的地雷」。

```js
// 改动后
this.eWeightBase = new Float64Array(this.eWeight);   // 真正的独立副本
```

### 2.2 新增 API（`src/brain/connectome.js`）

| API | 作用 |
|---|---|
| `setPlasticity({eta, decay, renorm})` | 配置 Hebbian 算子；`eta ≤ 0` 视为关闭（默认） |
| `restoreBioWeights()` | 把 `eWeight` 复位到生物原件（保留 `dnGains`） |
| `measureDrift()` | 相对漂移 `Σ\|W−W_bio\| / Σ\|W_bio\|`，O(E)≈3 µs，供网页低频展示 |

算子嵌在 `step()` 的第 2.5 步（动力学迭代之后、节点同步之前），每帧对全部 1296 条边各更新一次：

```
W_ij ← W_ij + η · ( h_i · h_j − decay · W_ij )
```

`h` 是当帧 3 次迭代后的最终活动。它**不需要全局误差信号、不需要反向传播** —— 这是它能被称作「生物规则」而不是「优化器改连接组」的原因。

`renorm: true` 时每帧再把每个突触后神经元的 `Σ|W_in|` 拉回 1（连接组的原始归一化约定）。实测**必需**，见 §3。

默认 `eta = 0` ⇒ 整段跳过 ⇒ 引擎行为与改动前逐位一致。

### 2.3 网页接入（按项目既有惯例）

| 文件 | 改动 |
|---|---|
| `src/brain/connectome.js` | 上述 API + 隐患修复 |
| `src/app.js` | `PLASTICITY_LEVELS` 三档 + `setPlasticityLevel()` + 漂移遥测 + 重生/重置时复位 W |
| `index.html` | 工具栏加「可塑性:」标签 + 三档按钮组（照 `WARP:` 的既有模式），`.runtime` 加 `flex-wrap` |
| `src/i18n.js` | 新增 4 个键（zh/en 双语齐备） |

档位 **OFF / η=1e-5 / η=1e-4**，默认 OFF。开启后 `#labelPlasticityDrift` 实时显示相对漂移百分比。**本次未启动服务器、未打开预览。**

## 3. 探针：固定读出层时的效果（`experiments/_p4_1_probe.mjs`）

方法：读出层用 A 臂（对着冻结 W 训出来的 1369.5 帧冠军）**冻结不动**，只让 W 可塑，20 测试种子 × 上限 1800 帧。

| 设置 | 相对漂移 | 存活帧 | vs 基线 1369.5 |
|---|---|---|---|
| **W 冻结（基线）** | 0 | **1369.5** | — |
| η=1e-5，无守恒 | 0.0224 | 1226.4 | −10.4% |
| η=1e-5，+守恒 | 0.0220 | 1339.8 | **−2.2%** |
| η=1e-4，无守恒 | 0.3448 | 992.1 | −27.6% |
| η=1e-4，+守恒 | 0.2525 | 1138.8 | −16.8% |
| η=1e-3，无守恒 | 14.98 | 1039.5 | 跑飞 |
| η=1e-2，无守恒 | 157.66 | 1039.5 | 跑飞 |

三条机制结论：

1. **漂移是线性的、不收敛。** η=1e-5 轨迹 `0.0047 → 0.0079 → 0.0103`（每 200 帧）。可用 η 窗口极窄 —— 跨 3 个数量级就从「掉 2%」到「把整个连接组冲成随机网络」。
2. **规则确实吃环境，但方向是正反馈雪崩。** 同 η=1e-3：喂真实弹幕 → 漂移 **14.98**；把感觉输入冻结成常数 0.5 → 漂移 **0.0088**。差 **1700 倍**。真实输入造出相关的 `h_i·h_j`，触发失控放大；恒定输入下 decay 项对称抵消。**归一化守恒是必需的**，否则真实场景下一局就把网络冲垮。
3. **一生可塑没有出现学习。** W 跨 20 局累积后，前 5 局成绩 `548,1249,368,1800,1249` ≈ 后 5 局 `1800,1249,368,1755,1249`，而且 η=1e-4 / 1e-3 / 1e-2 **给出完全相同的序列** —— 网络已饱和成同一状态。**没有「越玩越会」，只有「越玩越糊」。**

顺带一个反直觉细节：η=1e-5 的 2.2% 漂移掉了 10.4%，而 P4 评估报告 §3.2 里**同样 2.2% 的随机扰动只掉 2%**。说明 Hebbian 的漂移是**结构性的**（沿「强化共激活对」这个特定方向匀速走），比同量级的随机噪声更伤。

## 4. 协同训练：读出层在「W 可塑」环境里重训（CEM 种子 20260916）

探针的结论有硬伤：读出层从没被要求应付一个会动的 W。所以必须让它在可塑性开启的环境里从头训。三臂各 80 代 × 64 候选 × 12 种子 = 61,440 局，共用同一 CEM 随机源（`mulberry32`）。

| 臂 | 测试均值 | 触顶 1800 | 随机基线 | 学习增益 | 峰值漂移 |
|---|---|---|---|---|---|
| **none** W 冻结 | 1369.5 | 10/20 | 853.4 | +516 | 0 |
| **h5** η=1e-5 +守恒 | **1451.7** | **12/20** | 853.1 | +599 | 0.0323 |
| **h4** η=1e-4 +守恒 | 1371.5 | **4/20** | 902.1 | +469 | 0.5302 |

**回归门**：none 臂复现 1369.55，与未改源码前的 A 臂 **Δ = 0.00 帧** ✅ —— 训练语义零漂移。

初看 h5 是本项目**第一次跑赢 v1 基线**（+6.0%）。但逐种子看：

```
[h5 vs none] 均值差 +82.1 | 配对中位差 0.0 | 胜 5 / 负 3 / 平 12
```

**均值增益由 3 个种子独占**（80019 +1153、80018 +447、80015 +204，合计 +1804 = 全部增益的 110%）。剔除这 3 个，剩下 17 个种子上 h5 反而**差 9.5 帧**。这正是 P0 那次「+2.9% 被 80007/80010 拉高」的同一种假象。

h4 则明确变差：均值持平但触顶从 10/20 掉到 **4/20**。

## 5. 关键复现：换一颗 CEM 训练种子（决定性）

**单次 CEM 训练本身就是一个有噪声的样本。** 所以复现必须重跑训练过程，而不只是换测试种子。用 CEM 种子 20260917 重跑 none 与 h5：

| CEM 种子 | none | h5 | **h5 − none** |
|---|---|---|---|
| 20260916 | 1369.5 (10/20) | 1451.7 (12/20) | **+82.1** |
| 20260917 | 1306.3 (9/20) | 1289.8 (**1/20**) | **−16.5** |

**符号翻转。** 而且：

- 冻结臂自身跨 CEM 种子的极差 = **63.3 帧** —— 光换一颗训练随机源就有这个抖动
- h5 自身跨 CEM 种子的极差 = **161.8 帧**（比冻结臂还大）
- h5 的触顶数从 12/20 崩到 **1/20**
- s17 上配对中位差 −85.5，胜 9 / 负 10 / 平 1

**效应量（+82 / −17）小于等于噪声（63）⇒ 「h5 优于冻结」不成立。**

## 6. 交叉环境检验：为什么它不成立（`experiments/_p41_cross.mjs`）

读出层权重与运行环境解耦 —— 可以把 X 臂训出的权重放进 Y 臂的环境跑。20 测试种子，格子内为「均值 (触顶数)」：

| 权重来源 \ 环境 | W 冻结 | η=1e-5 | η=1e-4 |
|---|---|---|---|
| **none** | **1369.5** (10/20) | 1339.8 (9/20) | 1138.8 (2/20) |
| **h5** | 1373.6 (10/20) | **1451.7** (12/20) | 1262.5 (1/20) |
| **h4** | 1357.0 (1/20) | **1636.2** (13/20) | 1371.5 (4/20) |

三条读数：

1. **h5 的读出策略本身并不更优。** h5 权重放进冻结环境 = 1373.6 vs none 的 1369.5（+4.0，**胜 6 / 负 7 / 平 7**）。它的 +82 只在自己那个可塑环境里出现 ⇒ **收益来自「协同适应」，不是「找到了更好的策略」。** 佐证：none 的权重放进 h5 环境反而掉到 1339.8（−29.8）。
2. **交叉组合能赢过两个对角线。** h4 权重 × η=1e-5 环境 = **1636.2（13/20）**，是全表最高分，高于 h5 自己的对角线 1451.7、也高于 h4 自己的对角线 1371.5。两个「未经优化」的交叉格反而拿第一 —— 这直接说明**在 ±5% 这个量级上，单跑排名没有意义**。
3. **逐种子看是策略特化，不是整体变强。** h5 权重在冻结环境下把 card2 从 ~1700 砸到 ~903（6 个种子里 5 个），同时把 card0 从 ~690 拉到 1800（7 个种子里 4 个）。均值恰好抵消 → 均值持平。这是**换了一个取舍点**，不是变强。

**之前「20 个测试种子实际只有 3 个独立场景、n_eff ≈ 3、置信度虚高 7 倍」的判断需要更正：**

- **A 臂的种子确实产生不同场景** —— card0 极差 99、card2 极差 447。对 A 而言「n_eff ≈ 3」不成立。
- card1 的极差 0 是**天花板效应**（A、C 全部打满 1800），不是伪重复。

P0-2 的结论（B 变差）不受影响，因为 B 是在三张符卡上**同时**落后的。但之前那个「虚高 7 倍」的折扣力度是被夸大的，`MEMORY.md` 已同步更正。

## 8. 结论：P4-1 到底改变了什么

**会改变（真实发生）：**

- W 从常量变成每帧自更新的量 —— 一局内线性漂移，不收敛
- 系统行为可分辨地变化：漂移 2% 时掉 ~2%，漂移 25% 时掉 ~17%，漂移 >100% 时退化成随机网络
- 叙事升级：「冻结的真连接组」→「真连接组 + 生物可塑性」，且这仍是一条局部生物规则（无全局误差、无反向传播），溯源链完整
- 网页多一个可现场演示的旋钮 + 实时漂移读数

**不会改变（已否证）：**

- **能力上限。** 效应量 ≤ 训练噪声，符号会翻转
- 它不带来「学习」：一生可塑下前 5 局 ≈ 后 5 局，且不同 η 给出完全相同的成绩序列
- 它不找到更好的策略：h5 权重放进冻结环境与 none 打平（胜 6 / 负 7 / 平 7）

**它真正的用处是科普。** naive Hebbian 在真实输入下失控、必须靠稳态归一化压住 —— 这正是神经科学里「大脑为什么需要 homeostatic plasticity（Turrigiano）」的教科书演示。作为装置（而不是作为变强手段），它是加分的。

**对项目路线的意义：** 「冻结 vs 可塑」这个轴可以结掉了。剩下的候选只有 P1（加宽出口，但输入维度仍是 16 个 DN）与「换任务」。而「继续加神经元」早已被实测否掉。
