### 2.1 符卡周期 ≈ 3.74 秒

对链像素面积 A(t) 去线性趋势后做自相关：

```

lag= 5 (0.47s)  +0.608
lag= 9 (0.87s)  +0.092
lag=10 (1.00s)  -0.053   ← 过零点
lag=19 (1.87s)  -0.879   ← 最深负相关
lag=25 (2.47s)  -0.550
```

自相关曲线**单调衰减**，在 lag=19（1.87s）处达到**最深负相关 −0.879**，然后回升。这是典型的**半周期**特征：

**半周期 1.87s → 全周期 ≈ 3.74 s**

A(t) 曲线上的局部低谷间隔为 1.60s 与 2.07s（平均 1.83s），与半周期吻合，互为佐证。

### 2.4 下落幕速度 ≈ 104 px/s（GIF 坐标）

**方法**：在画面下半屏铺 60 个 28×28 采样窗口，逐帧做块匹配（搜索半径 ±14px），取位移中位数。

```
下半屏窗口数: 60
有效帧对: 78 / 78
vx: 中位 = +0.00 px/s    (水平无整体漂移 ✓)
vy: 中位 = +103.85 px/s  (向下 ✓)
|v| 中位 = 109.46 px/s
```

**方向验证**：vx ≈ 0（无水平漂移）、vy > 0（向下），**运动方向完全符合"下落幕"的物理预期**，这是一个重要的正确性佐证。

**换算到东方标准游戏区（384 × 448）**：

```
缩放比 = 384 / 780 = 0.4923
vy ≈ 103.85 × 0.4923 ≈ 51.1 px/s
60fps 下每帧位移 ≈ 0.85 px/帧
```

> 作为参照，东方游戏内常见弹幕速度为 1~5 px/帧，**0.85 px/帧 属于"很慢"档位** —— 与用户对这张符卡的描述（"弹幕移动是很慢很慢那种"）完全一致。

### 2.5 放射状运动的分区验证

按极坐标分 3 环带 × 4 象限，逐格测径向速度：

| 环带 | -180~-90° | -90~0° | 0~+90° | +90~+180° |
|---|---|---|---|---|
| 60~180px | +0.0 | +3.8 | **+76.1** | **+47.0** |
| 180~320px | +0.0 | +8.7 | **+73.4** | **+60.6** |
| 320~480px | +5.0 | +21.6 | **+45.3** | **+40.4** |

（单位 px/s，值为径向分量中位数）

**关键发现**：右半屏（0°~180°，即画面下方）存在**明确的向外径向运动（+40 ~ +76 px/s）**，而左半屏（画面上方）几乎为零。

这解释了为什么**全局相位相关会返回 0**：画面上下半区的位移矢量方向相反、量级相近，**全局平均后相互抵消**。这也正是为什么必须用**分区局部光流**才能测出真实运动。

## 三、未能测出的参数（诚实说明）

### 3.1 螺旋转速（角速度）

**尝试的 4 种方法全部失败**：

| 方法 | 结果 |
|---|---|
| 角向剖面互相关（9 环带） | 大量帧对 Δθ = 0 |
| 相位追踪（1~6 阶谐波，29 环带） | \|ω\| 在 0~80°/s 乱跳，方向不可辨 |
| 极坐标图 2D 平移搜索（72 斜线行） | 高置信帧对全部 Δθ = 0 |
| 全局相位相关 FFT | 位移 (0,0)，峰值仅 0.04~0.20 |

**原因分析**：

1. **帧率过低**：有效帧率仅 ~10.5 fps（帧时长 60/70/130/140ms 混杂），而螺旋转动速度快 → 帧间角位移超过半个空间周期 → **混叠（aliasing）**
2. **方向相消**：螺旋是**多臂放射状**结构，角向剖面上有多个相位中心，相邻帧的角位移在不同的环带上符号相反，全局互相关无法收敛
3. **素材非匀速**：帧时长不均匀说明 GIF 经过**降帧/混剪**处理，破坏了等时间间隔采样的前提

**结论：这不是方法问题，而是信息论上的极限 —— 该 GIF 的采样率不足以约束螺旋的角速度。**

### 3.2 发射间隔

同理，由于无法可靠追踪单颗子弹的生成时刻（帧率不足 + 子弹密集重叠），**发射间隔无法测定**。

从 A(t) 曲线可粗略看出粒子增删的节奏（上升段约 12~20 帧 ≈ 1.2~2 秒），但这混合了"生成"与"离场"两个过程，**不能直接等同于发射间隔**。

## 五、方法学附注（重要教训）

### 5.1 「下落速度 312 px/s」是一个错误结论

**分析早期，用"相邻帧垂直剖面互相关"得到过 v = 312.3 px/s 的结果。**

后续用更严格的方法验证时，**该结果被证伪**：

| 验证方法 | 结果 |
|---|---|
| 全局相位相关 FFT | 位移 (0, 0)，78/78 帧对 |
| 块匹配光流（全屏 144 窗口） | vy 中位 +57 px/s（**注意：是另一套窗口集**） |
| 块匹配光流（下半屏 60 窗口） | vy 中位 +103.85 px/s |
| 亮度亚像素质心 | dcy/dt = +1.52 px/s，残差 std = 6.33px（信噪比 < 0.25） |

**312 px/s 的来源**：垂直剖面互相关在**周期性/自相似纹理**上极易产生虚假匹配。本符卡的外围弹幕是**规则栅格**排列（等间距、等尺寸），互相关会匹配到"相邻一颗子弹"而非"同一颗子弹的位置"，从而**虚增位移 3~4 倍**。

> **教训：当信号具有周期性结构时，单一互相关结果必须用独立方法交叉验证。本报告最终采用「下半屏块匹配 + 方向一致性检验」的结果（104 px/s），因为：**
> 1. 它用了**二维块匹配**（同时约束 dx, dy），比一维剖面更难产生虚假匹配
> 2. **vx ≈ 0** 符合"纯下落"的物理预期（一维剖面法无法提供这一验证）
