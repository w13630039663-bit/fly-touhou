**核心结论（证据版）**：
1. **A.2 主判据证实**：加性两段归一化完全反转回归（+302.6f, p=0.0046, 方向一致 18/20），统计上与 v1 打平（p=0.91）。600 细胞图在修好读出契约后恢复 80 细胞图水平。
2. **稀释假说的最终形态**：归一化修复后 Δ₀(496) 从 +120.7 → **+391.8f** —— 496 新中间神经元不是死重，是**被错误的权重口径饿着**。「让 520 个神经元发挥正常水平」的答案=改归一化，不必换细胞。
3. **C.1b 语义兑现**：b 图上 Δ₀(496)=+9.4f ⇒ 新中间细胞绕过读出后确实退化为旁观者；Δ₀(520)=−101.5f ⇒ 24 个新输入细胞在 b 契约下净负贡献。b 对旧 v600 的改善方向为正但主判据 p=0.055 **不达标**，按纪律只说「疑似有益，未证实」。
4. A vs B(600b)：Δ=163.3f p=0.085 不显著——两修法统计上难分，但 A 是唯一主判据过线者 ⇒ **主线转 600a**。
5. **B 案（322 增益把手）判负，机制干净利落**：冠军权重 `exc=−0.606→钳制 0, inh=0.024`——CEM 找到**把 DN 输入几乎关闸**的退化解，训练 plateau 全场最高 (1168.7) 而独立测试回落到 1386.3f（vs A −151.9f, p=0.126）。Δ₀(496)=−120.2f 与关闸语义自洽（增益塌缩后新细胞变噪声）。**结论：读出把手自由度过大 = 过拟合通道；固定 α=1 的加性契约已在吃掉新细胞全部信息，「新细胞有信息但固定读出不吃」不成立。** 这是 plateau≠test 纪律的一次活体示范。
6. **首个池修复后的干净对照（B.2 场内）**：ctrl 在自身重连图上训练与评估，test 1397.8f vs bio 1386.3f, Δ=−12f **p=0.9351 完美平手** ⇒ 「拓扑优越性」主张在有增益把手的宽松读出口径下依然为零；checkpoint600ag 的对照字段已标 VALID（历史 checkpoint600/600a/600b 的对照仍为 INVALID）。
7. **D 案（300×128 对称放大）终审门未过 ⇒ 不宣称「规模带来能力」**：600ax vs v1x Δ=+116.0f 但主判据 bootstrap **p=0.3776 不显著**（符号检验 p=0.0414、15/20 胜作为次要口径如实列出，不改判）。定稿表述：**「本读出契约下，规模在统计上与 80 细胞打平；预算×3 对两个规模都是伤害（v1 −206.5f、600a −83.8f 的 test 回落），未发现可宣称的规模收益」**。附带证物：600ax 的 Δ₀(496)=+493.4f（新细胞净贡献再创新高，仍换不来总增益——「贡献≠优势」的又一例）。
8. **冠军定稿 = v600a（100×64 原预算）**：1538.2f 全表最高（对 v1 无统计差异、对局数 14/20 反而领先），UI 已接入 `?brain=v600a`；v600ax 非冠军 ⇒ 不接入 UI（避免用回放更差的数据集误导用户）。

## 意外工程发现：--workers 模式下对照污染 bug（播种后现形）
- **症状**：P0.0 播种后，Matched Control 的 CEM 轨迹与 bio 逐位相同（gen1–100 全等）。
- **根因**：`train.js` 旧 `makeEval` 在并行模式忽略 brain 参数——评估池按 bio 图初始化，对照候选实际在 bio 拓扑上打分。未播种时代码同样错误，只是被随机性掩盖。
- **修复**：`runTrack` 每轨独立池；冒烟验证 bio 779.9 vs ctrl 581.9 分叉 ✓。
- **波及面**：checkpoint600a/b 的 `matchedControl/topologyAdvantage*` 字段已标 `controlIntegrity: INVALID`；**checkpoint600（历史）的对照基准同源受污**，其「对照 1567/878/880 波动」与 topologyAdvantage 结论降级为不可引用（原结论本就主张拓扑不显著，不影响主结果）。主判据（四方配对对决）全部使用 bio 冠军权重，不受该 bug 影响。
- v600a/b 的 bio 训练与独立测试基准均在正确图上产出，可信。
